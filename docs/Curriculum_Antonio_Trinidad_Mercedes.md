## Proyectos destacados

### PWA Iglesia 10ma Quinta El Buen Samaritano

Aplicación web progresiva (PWA) completa para una congregación en San Pedro de Macorís, República Dominicana. Incluye más de doce pantallas funcionales: programa semanal con horarios por día, galería de videos con reproductor YouTube integrado, transmisión en vivo con chat embed, confirmación de asistencia a eventos con cupo en tiempo real, diezmos y ofrendas con selector de monto y método de pago, suscripción al boletín, muro de peticiones de oración, quiénes somos, contacto con mapa y búsqueda global con highlight de resultados. Diseño mobile-first con sistema de tokens de color, modo oscuro completo y navegación por tabs fija.

**Tecnologías:** Next.js 15 (App Router), TypeScript, Tailwind CSS v4, CSS custom properties, PWA.

### EvaluaPro

Plataforma académica para gestionar tareas, instrumentos de evaluación, resultados y reportes según el rol del usuario. Permite crear rúbricas y listas de cotejo, consultar estadísticas, visualizar resultados desde el panel del estudiante y generar vistas imprimibles.

**Tecnologías:** React, Node.js, Express, MongoDB, Mongoose y JWT.

### Portafolio Fullstack y Blog Técnico

Plataforma personal para presentar proyectos, servicios y artículos técnicos. Incluye un panel de administración privado para gestionar proyectos, publicaciones, categorías, mensajes y comentarios moderados, además de optimización SEO.

**Tecnologías:** React, Vite, Node.js, Express, MongoDB y JWT.

### Panel Operativo para Servicios

Dashboard para el seguimiento de clientes, solicitudes de soporte, tickets y métricas internas. Incluye filtros rápidos, estados de seguimiento y flujos centralizados para facilitar la gestión de servicios.

**Tecnologías:** React, Express y MongoDB.

### API de Automatización de Contenido

Backend diseñado para recibir datos desde formularios, ejecutar webhooks y organizar mensajes según su estado dentro de un flujo de trabajo.

**Tecnologías:** Node.js, Express, MongoDB y Webhooks.

### Sitios web para iglesias y organizaciones educativas

Diseño y desarrollo de sitios web modernos y responsivos para comunicar actividades, programas, eventos, servicios y contenido institucional. Los proyectos fueron adaptados a la identidad, el público y las necesidades particulares de cada organización.

**Tecnologías:** React, JavaScript, HTML5, CSS3 y herramientas de diseño web.
